Synapse — Privacy Policy

Browser extension · Last updated: 2026-10-19 · Version 0.15.1
Short answer: Synapse does not collect, transmit, store, or process any user data.
It has no servers, no analytics, and no network endpoints. Everything runs on your own machine.

What this extension does

Synapse lets an AI coding agent on your own computer drive the browser you are already logged into (open tabs, read the rendered page, click and type, capture the page's own network responses). This is a local automation tool in the same category as browser devtools / CDP drivers — it helps you automate your sessions on your machine.

Data collection 数据收集

None. The extension makes no outbound network requests. It contains no analytics, no advertising, no tracking, and no third-party SDKs. No information is sent to the developer or any other party, ever.

Local loopback only 仅限本机回环

The extension can connect exclusively to 127.0.0.1 (your own machine), on ports started by a local agent program you run (the "agent bridge", default range 9521–9540). No remote servers are contacted. If that local bridge is not running, the extension stays completely quiet and inactive.

Permissions and why

  • debugger / tabs / <all_urls> — required to read and act on tabs you are logged into, across any site, for the automation tasks you initiate.
  • storage / alarms / sidePanel / tabGroups — local bookkeeping and the settings panel; all state stays on your machine.

Your content, your business 页面内容

While you run a task, page content (DOM, forms, network responses) is passed between the extension and your own local agent process over loopback. It never leaves your machine through this extension. What your agent program does with it is governed by that program's own policies, not this extension's.

Children, cookies, contact

The extension does not knowingly collect information from children, does not use cookies or trackers, and does not receive your data in any form. For questions: this extension is a self-contained local tool; there is no data handling to inquire about.

中文摘要：本扩展不收集、不传输、不存储任何用户数据；没有任何服务端、 无遥测、无第三方 SDK。它只与你自己在本机启动的 agent 程序通过回环地址（127.0.0.1）通信； 未启动本地桥时扩展完全静默。页面内容仅在你本机内于扩展与你的 agent 之间流转， 绝不通过本扩展离开你的电脑。
